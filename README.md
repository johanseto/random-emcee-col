# random-emcee-col

Generadores aleatorios de participantes de Red Bull Batalla 2026:

- Colombia: los 16 MCs de la Final Nacional.
- Internacional: los 16 MCs de la Final Internacional.

## Uso

```bash
npm test
node bin/global.js
node bin/international.js
```

Al instalar el paquete globalmente, también están disponibles los comandos
`random-emcee-col` y `random-emcee-internacional`.

## Fuentes de las listas

- [Red Bull Batalla Colombia 2026](https://www.redbull.com/co-es/red-bull-batalla-colombia-todo-sobre-la-final-nacional-2026)
- [Red Bull Batalla Final Internacional 2026](https://www.redbull.com/int-es/el-menor-campeon-final-internacional-batalla-2026)
